ABOUT THE PROJECT

Secure Student Records
Powered by Blockchain

The Student Record Management System using Blockchain Technology is a decentralized platform that securely stores and manages student academic records. Blockchain ensures that every record is immutable, transparent and easily verifiable.

Secure Storage

Student records are stored securely using blockchain technology.

🛡️

Immutable Records

Decentralized Access
